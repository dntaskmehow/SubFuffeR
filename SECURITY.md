# Security and Responsible Use

SubFuffeR is intended for assets you are authorized to test, including programs whose HackerOne policy explicitly permits your activity.

The HackerOne integration imports structured scope and blocks targets that do not match eligible assets. It does not grant authorization, interpret every policy exclusion, or guarantee bounty eligibility. The operator remains responsible for reading the live program policy, respecting rate limits, avoiding prohibited testing, and reporting findings through the program's required channel.

Do not use this project against third-party assets without written authorization. Do not include secrets, tokens, private URLs, or sensitive finding details in public issues. For a project vulnerability, contact the repository owner privately.
