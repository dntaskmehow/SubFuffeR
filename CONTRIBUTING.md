# Contributing

Keep changes focused on authorized, auditable security research workflows.

- Do not add persistence, privilege escalation, firewall changes, stealth behavior, or credential storage.
- Keep external tool execution in argument arrays with cancellation support.
- Preserve the HackerOne scope gate and explicit ffuf action.
- Do not run reconnaissance during development or CI.
- Document new dependencies, pinned versions, and platform requirements.
- Do not commit API tokens, target data, or real finding evidence.
